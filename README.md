文件双端
最初，我只是想躺在床上看视频，不想串流。

后来，我想躺在床上看书。后来，我想听音乐。后来，我想保存图片。再后来，因为生活所迫不得不上班，我还想听书。

这就是这个项目的全部来源。

它是什么？
文件双端是一套 “电脑 + 手机”之间的媒体直连方案。

后端跑在你的电脑上（Windows / Linux 取决于编译方式，顺带一提linux我没测试过），前端装在你的手机上（Android 6+）。不需要公网 IP，不需要域名，不需要会员，不需要专门买一台 NAS。

只要电脑和手机在同一个局域网，或者你能通过某种方式访问到那台电脑——你就赢了。

它不是 NAS。它只是一个把电脑上的文件“搬”到手机上用的东西。

它能做什么？
🎬 视频
浏览电脑上的视频文件夹

点击即播，支持进度拖动

自动连播（同一个文件夹里的视频串成剧集）

手势控制：双击暂停、长按加速、滑动调进度/音量

🎵 音频
浏览电脑上的音频文件

后台播放，通知栏控制

循环模式：列表循环 / 单曲循环 / 随机播放

歌词支持：智能匹配 + 手动映射

🖼️ 图片
浏览电脑上的图片文件夹

按拍摄日期自动分组（今天 / 昨天 / 某月某日）

排序方式：名称 / 大小 / 修改时间 / 拍摄日期

拍照上传：手机拍完直接存入电脑

📖 文本
浏览电脑上的文本文件（.txt）

分页阅读，翻页流畅

TTS 听书：点击朗读，自动翻页，自动续读


怎么用？
电脑端：双击运行 FileServer.exe

手机端：安装 文件双端.apk

输入电脑的 IP 地址，点击连接

没了

不需要配置端口转发，不需要注册账号，不需要挂载磁盘。
